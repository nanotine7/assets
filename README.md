# 資產盤點掃碼系統

一個手機、電腦都能用的線上盤點小工具。匯入資產清單後，用掃碼機或手機相機掃條碼，就能即時核對這項資產在不在清單裡，並自動記錄。不用安裝、打開網址就能用。

## 🔗 線上網址

https://nanotine7.github.io/assets/

## 這個工具能做什麼

- 📋 **匯入清單**：支援 Excel 與文字檔（.xlsx／.xls／.csv／.txt／.tsv）。
- 🆓 **自訂比對欄位**：清單欄位名稱完全自由，匯入後自己從下拉選單選哪一欄要拿來跟掃描結果比對——不同稽核表單的欄位不用一樣。
- 🔍 **掃碼核對**：掃到的條碼會即時比對清單，顯示「✅ 找到／❌ 找不到／⚠️ 重複」。
- 📷 **相機自動辨識**：手機相機對準條碼、對焦清楚後會自動比對，不需要一直按按鈕；讀不到時可按「強制重新辨識」。
- 🔌 **掃碼機隨時可用**：接上條碼掃描槍，不管畫面在「掃碼機」還是「手機相機」模式都能直接掃，兩種方式可以搭配著用。
- 🔔 **提示音＋震動**：每次掃描成功、重複或找不到，都會有不同的提示音與震動，操作者不用一直盯著螢幕確認。
- 📊 **即時統計**：已掃描次數、核對正確、找不到、以及「尚未盤點」（清單中還剩幾筆沒掃到）。
- 💾 **自動存檔**：掃描進度會自動儲存在手機／電腦本機，關閉網頁或隔天再打開都能詢問是否繼續上次進度，不怕盤點到一半中斷。
- 📜 **掃碼記錄**：每一筆掃描都留下紀錄，方便事後檢查。

## 怎麼使用

1. 打開上面的網址。
2. 點「📂 選擇檔案匯入」，把你的 Excel 或 CSV 清單匯入，再從下拉選單選好要比對的欄位。
3. 選擇掃描方式：
   - **🔌 掃碼機**：接上條碼掃描槍，掃到自動送出（切到相機模式時也一樣能用）。
   - **📷 手機相機**：對準條碼、對焦清楚後會自動辨識比對；讀不到才需要按「強制重新辨識」。
   - **📸 拍照辨識**：iPhone 建議用這個，把條碼拍清楚即可辨識。
4. 掃描結果、提示音／震動與統計會即時顯示。
5. 盤點到一半要離開，直接關閉網頁即可——資料已自動存在本機，下次打開會問你要不要繼續。
6. 要開始全新一批盤點時，按「🗑️ 清除全部重新開始」。

## 小提醒

- iPhone（iOS Safari）要用相機，網址必須是 **https**（本網站已符合）。
- 清單與掃描記錄只存在你自己的裝置瀏覽器裡（localStorage），不會上傳到任何伺服器；但也表示**換一台裝置或清瀏覽器資料就會不見**，重要紀錄建議定期用「📜 掃碼記錄」核對備份。
- 震動功能目前僅支援 Android；iPhone（iOS Safari）尚不支援網頁震動 API，仍會有提示音。
