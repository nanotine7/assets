# 資產盤點掃碼系統

一個手機、電腦都能用的線上盤點小工具。匯入資產清單後，用掃碼機或手機相機掃條碼，就能即時核對這項資產在不在清單裡，並自動記錄。不用安裝、打開網址就能用。

## 🔗 線上網址

https://nanotine7.github.io/assets/

## 這個工具能做什麼

- 📋 **匯入清單**：支援 Excel 與文字檔（.xlsx／.xls／.csv／.txt／.tsv），可自己選哪一欄是條碼。
- 🔍 **掃碼核對**：掃到的條碼會即時比對清單，顯示「✅ 找到／❌ 找不到」。
- 📊 **即時統計**：自動計算已掃描次數、正確數、找不到的數量。
- 📜 **掃碼記錄**：每一筆掃描都留下紀錄，方便事後檢查。

## 怎麼使用

1. 打開上面的網址。
2. 點「📋 資產清單」，把你的 Excel 或 CSV 清單匯入，選好條碼欄位。
3. 選擇掃描方式：
   - **🔌 掃碼機**：接上條碼掃描槍，掃到自動送出。
   - **📷 手機相機**：對準條碼後，按一下「🔍 讀取條碼」才會辨識（不會一直亂讀）。
   - **📸 拍照辨識**：iPhone 建議用這個，把條碼拍清楚即可辨識。
4. 掃描結果與統計會即時顯示在下方。

## 小提醒

- iPhone（iOS Safari）要用相機，網址必須是 **https**（本網站已符合）。
- 清單資料只在你自己的裝置上處理，不會上傳到任何伺服器。
